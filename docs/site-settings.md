# Cấu hình website

Các giá trị trong **Settings → General**:

| Thiết lập | Giá trị |
|---|---|
| Site Title | Góc Sống Việt |
| Tagline | Tri thức, trải nghiệm và cảm hứng mỗi ngày |
| Site Language | Tiếng Việt (`vi`) |
| Timezone | `Asia/Ho_Chi_Minh` (UTC+7) |
| Date Format | `d/m/Y` (ví dụ: 10/09/2026) |
| Time Format | `H:i` (ví dụ: 18:45) |

Địa chỉ local của website: `http://localhost/wordpress_nguyentranthanh/`.
